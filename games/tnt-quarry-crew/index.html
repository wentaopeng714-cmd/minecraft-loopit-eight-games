TNT Quarry Crew

  1. Tap a building block to attach TNT. It flashes, counts down, then explodes.
  2. Remove supports so the marked crown blocks fall to the quarry floor.
  3. Clear all crown blocks with 3 charges. Unused TNT earns a bonus; the next site has a new structure.
