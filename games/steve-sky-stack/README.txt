Steve Sky Stack · 无限方块叠高 · v0.3
旧页面请刷新后游玩。

固定斜侧视角，随高度跟随。点DROP或Space，实时重叠比例与绿色落点显示叠放位置。
目标：一座连续无限塔，失去重叠时结束；没有20层关卡弹窗。
判断：判断重叠和节奏，连续完美落块恢复宽度；保住面积来挑战高度和最高分。
成长：每3层变换材质与颜色；随高度进入日落、云层、雨天、雷暴和夜空，连续攀升不中断。

本机试玩：http://127.0.0.1:5190/steve-sky-stack/dist/
打开右上角 ? 可查看英文简短说明并暂停。

本地开发：npm ci，然后 npm run dev。
构建：npm run build。运行规则检查：npm test。
dist 是完整静态网页，请通过HTTP服务器打开，不要直接双击file://页面。
