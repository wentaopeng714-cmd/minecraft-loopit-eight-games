苦力怕投掷战 · Creeper Toss — Blockyard Duel
独立单人对战游戏，与矿车游戏分开。

玩法
你是蓝色护甲的史蒂夫，对手是红色护甲的史蒂夫。
把苦力怕扔向对手，炸开木箱和石块掩体，打空红色生命条即可获胜。
苦力怕会弹跳、闪烁并爆炸。红色落地圈出现时，移动躲开。

操作
手机布局：左侧摇杆移动。在场地或右侧 TOSS 键上拖拽瞄准，松手投掷。
点一下 TOSS 也能直接向对手投掷。
电脑：WASD / 方向键移动，鼠标拖拽瞄准，空格快速投掷。
右上角 ? 查看玩法并暂停。获胜后 NEXT RIVAL 继续连胜，失败后 START A NEW RUN 重开。

版本内容
纹理角色、蓝红护甲、带四肢的苦力怕道具；后摆、挥臂、脱手、收势和受击动作。
可破坏掩体、弹道与落点预览、爆炸倒计时、击退、音效、村民观众、胜负与重开。
电脑与手机横竖屏布局已在浏览器中检查。手机尺寸测试并不等同于实体手机实测。

1.1 目标与反馈更新
目标常驻显示：打空红色生命条、迎战下一位对手、挑战连胜纪录。
实际伤害每点100分，破坏掩体每块25分，胜利300分，获胜时每点剩余生命50分。命中、落空和破坏掩体各有独立反馈。
结算显示本局分项、累计分数、最高纪录及下一对手生命值。连续获胜保留连胜和累计分数；每局恢复生命和掩体。对手生命6→7→8，进攻间隔逐步缩短并设下限。
